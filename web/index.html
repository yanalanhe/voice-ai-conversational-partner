Parlons

Voice AI conversation partner -- cascaded pipeline demo

What it is

A voice-first conversation partner for practicing a second language. You speak, it answers out loud, and it gently corrects mistakes by rephrasing them naturally instead of interrupting. You can cut in while it is talking, and the page shows how fast each reply came back.

How to use it

  1. Click Connect and allow microphone access.
  2. Speak a sentence, then pause for about a second.
  3. Listen to the reply. Start talking to interrupt it at any time.
  4. Check the latency panel below for the time to first audio, then click Disconnect when you are done.

Use headphones to avoid the agent hearing itself. If the server has no speech service configured, replies come from a fixed script and ignore what you say.
